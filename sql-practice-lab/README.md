# SQL Practice Lab

这是一个面向前端开发者的后端 SQL 与数据库练习包。

## 使用方式

1. 用浏览器打开 `index.html`。
2. 在 MySQL 8 中依次执行 `schema.sql`、`seed.sql`。
3. 按页面题目练习，参考答案也同步整理在 `answers.sql`。

## 业务场景

FlowMart 是一个新零售平台，数据覆盖会员、门店、员工、供应商、类目、商品、库存、订单、优惠券、支付、物流、退款、评价和客服工单。

## 覆盖能力

- 数据库与表结构设计
- 主键、外键、唯一索引、普通索引、CHECK 约束
- SELECT、WHERE、ORDER BY、LIMIT、分页
- JOIN、LEFT JOIN、多表关系
- GROUP BY、HAVING、聚合统计
- 子查询、EXISTS、CTE、递归 CTE
- 窗口函数、排名、移动累计
- INSERT、UPDATE、DELETE
- 事务、锁、回滚
- 视图、EXPLAIN、JSON 字段
- 数据质量检查与报表查询
