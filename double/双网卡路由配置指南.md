# 双网卡路由配置指南

## 网络环境
- **外网网卡**: Intel(R) Wireless-AC 9462 (WLAN) - 192.168.1.199
- **内网网卡**: Ugreen USB WiFi (WLAN 2) - 需连接到 172.16.x.x 网段

## 快速配置步骤

### 方法一：使用自动化脚本（推荐）

1. **以管理员身份运行** [`setup_dual_network.bat`](setup_dual_network.bat)
   - 右键点击脚本 → 以管理员身份运行
   - 按照提示操作

### 方法二：手动配置

#### 步骤 1: 连接 Ugreen USB WiFi 到内网

1. 打开 **Windows 设置** → **网络和 Internet** → **WLAN**
2. 找到 **WLAN 2 (Ugreen USB WiFi)** 网卡
3. 连接到内网的 WiFi 热点（172.16 网段）
4. 等待获取 IP 地址

#### 步骤 2: 查看内网配置

以管理员身份运行 CMD，执行：

```cmd
ipconfig /all | findstr /C:"WLAN 2" /A:10
```

记录以下信息：
- **IP 地址**: 172.16.x.x
- **默认网关**: 172.16.x.1（通常是这个）

#### 步骤 3: 添加静态路由

以管理员身份运行 CMD，执行：

```cmd
route -p add 172.16.0.0 mask 255.255.0.0 <内网网关IP> metric 10
```

**示例**（假设内网网关是 172.16.1.1）：
```cmd
route -p add 172.16.0.0 mask 255.255.0.0 172.16.1.1 metric 10
```

#### 步骤 4: 验证路由

```cmd
route print | findstr "172.16"
```

应该看到类似输出：
```
172.16.0.0    255.255.0.0    172.16.1.1    172.16.x.x     10
```

## 路由原理

| 目标地址 | 路由规则 | 说明 |
|---------|---------|------|
| 172.16.0.0/16 | → Ugreen USB WiFi | 所有 172.16.x.x 走内网 |
| 0.0.0.0/0 | → Intel 9462 | 其他所有流量走外网（默认路由） |

## 参数说明

- **`-p`**: 永久路由，重启后仍然有效
- **`172.16.0.0 mask 255.255.0.0`**: 匹配所有 172.16.x.x 地址（65536 个地址）
- **`metric 10`**: 路由优先级（数字越小优先级越高）

## 常见问题

### Q1: 添加路由时提示"请求的操作需要提升"
**A**: 必须以管理员身份运行 CMD

### Q2: 如何删除已添加的路由？
**A**: 以管理员身份运行：
```cmd
route delete 172.16.0.0
```

### Q3: 如何查看所有永久路由？
**A**: 
```cmd
route print -p
```

### Q4: Ugreen USB WiFi 无法连接到内网 WiFi
**A**: 
1. 检查网卡驱动是否正常
2. 确认内网 WiFi 信号强度
3. 尝试重启网卡：
   ```cmd
   netsh interface set interface "WLAN 2" disabled
   netsh interface set interface "WLAN 2" enabled
   ```

## 测试连接

配置完成后，测试连接：

```cmd
# 测试外网（应该通过 Intel 9462）
ping 8.8.8.8

# 测试内网（应该通过 Ugreen USB WiFi）
ping 172.16.1.1
```

## 高级配置

### 修改路由优先级

如果需要调整优先级，可以修改 metric 值：

```cmd
# 删除旧路由
route delete 172.16.0.0

# 添加新路由（更高优先级）
route -p add 172.16.0.0 mask 255.255.0.0 172.16.1.1 metric 5
```

### 添加更精确的路由

如果只需要访问特定子网（如 172.16.10.0/24）：

```cmd
route -p add 172.16.10.0 mask 255.255.255.0 172.16.1.1 metric 10
```

## 故障排查

### 查看当前活动路由
```cmd
route print
```

### 查看网卡接口信息
```cmd
netsh interface ipv4 show interfaces
```

### 查看网卡详细配置
```cmd
netsh interface ipv4 show config
```

### 追踪路由路径
```cmd
# 追踪到内网地址的路径
tracert 172.16.1.1

# 追踪到外网地址的路径
tracert 8.8.8.8
```
