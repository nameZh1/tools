# 双网卡路由配置指南

## 网络环境

| 网卡 | 接口 | 用途 | 连接 |
|------|------|------|------|
| WLAN (Intel 9462) | 接口 11 | 外网 | MiFi-C70A → Internet |
| WLAN 2 (Ugreen USB) | 接口 5 | 内网 | MERCURY_2318 → 172.16.x.x / 10.16.x.x |

## 网络拓扑

```
┌─────────────────────────────────────────────────────────────────┐
│                         你的电脑                                 │
│  ┌─────────────────────┐    ┌─────────────────────┐            │
│  │ WLAN (Intel 9462)   │    │ WLAN 2 (Ugreen USB) │            │
│  │ IP: 192.168.1.199   │    │ IP: 192.168.1.200   │            │
│  │ 网关: 192.168.1.1   │    │ 网关: 无 (关键!)    │            │
│  │ 接口索引: 11        │    │ 接口索引: 5         │            │
│  └──────────┬──────────┘    └──────────┬──────────┘            │
└─────────────┼───────────────────────────┼──────────────────────┘
              │                           │
              ▼                           ▼
     ┌────────────────┐          ┌────────────────┐
     │  MiFi-C70A     │          │ MERCURY_2318   │
     │  (外网热点)    │          │ (内网路由器)   │
     │  192.168.1.1   │          │ LAN: 192.168.1.1
     └───────┬────────┘          │ WAN: 172.16.x.x│
             │                   └───────┬────────┘
             ▼                           ▼
        ┌─────────┐              ┌─────────────────┐
        │ Internet│              │ 内网 172.16.x.x │
        └─────────┘              │ 内网 10.16.x.x  │
                                 └─────────────────┘
```

## 路由规则

```
172.16.x.x → WLAN 2 (Ugreen, 接口 5) → MERCURY_2318 → 内网
10.16.x.x  → WLAN 2 (Ugreen, 接口 5) → MERCURY_2318 → 内网
其他流量   → WLAN (Intel, 接口 11) → MiFi-C70A → 外网
```

## 配置脚本

### config_route_safe.bat（推荐）

安全版脚本，确保外网不中断：

1. 清理所有旧路由
2. 配置 WLAN 2 静态 IP（无默认网关）
3. 添加 172.16 和 10.16 永久路由
4. 连接 WLAN 2 到 MERCURY_2318
5. 设置高跃点数防止冲突

**使用方法**：右键 → 以管理员身份运行

### config_route.bat

标准版脚本，先连接再配置路由。

### restore_route.bat

恢复脚本，用于出问题时恢复网络。

## 手动配置命令

```cmd
:: 查看接口索引
netsh interface ipv4 show interfaces

:: 删除旧路由
route delete 172.16.0.0
route delete 10.16.0.0

:: 添加永久路由（-p 参数）
route -p add 172.16.0.0 mask 255.255.0.0 192.168.1.1 if 5 metric 10
route -p add 10.16.0.0 mask 255.255.0.0 192.168.1.1 if 5 metric 10

:: 查看路由表
route print | findstr "172.16 10.16"

:: 设置 WLAN 2 高跃点数
netsh interface ipv4 set interface "WLAN 2" metric=9999
```

## 故障排除

### 内网不通

1. 检查 WLAN 2 是否已连接 MERCURY_2318
2. 检查路由是否正确添加：`route print | findstr "172.16"`
3. 确认内网网关地址是否正确（172.16.1.1 或其他）

### 外网不通

1. 检查 WLAN 是否连接 MiFi-C70A
2. 检查默认路由：`route print | findstr "0.0.0.0.*0.0.0.0"`
3. 确保只有一个默认路由（通过 WLAN 接口 11）

### 重置网络

运行 `restore_route.bat` 或手动执行：

```cmd
route delete 172.16.0.0
route delete 10.16.0.0
netsh interface ipv4 set address "WLAN 2" dhcp
```
